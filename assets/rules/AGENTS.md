# Workspace rules

## Read the selected sources

Read the rule files explicitly selected for this session, in the supplied order. Use the workspace or project instructions to resolve scope and priority. Report a required source you cannot read instead of silently proceeding without it. Do not assume that a nearby file is part of the selected set.

When a task needs a skill, use the name exposed by the current tool. The displayed name can differ from the name in `SKILL.md`. Read the selected skill instructions and only the supporting material needed for the task.

## Ask for decisions

Give enough context for the user to answer without opening a log or reconstructing the conversation. Ask one decision per question. If you offer alternatives, say what changes under each choice. Label recommendations as recommendations, not as decisions the user has already made.

Group independent questions if that helps the user answer them. Ask dependent questions after the preceding answer. Use a question tool if the active instructions require it; otherwise use the available interaction surface. If required approval cannot be obtained there, report the blocker rather than assuming consent.

## Use personal voice preferences when supplied

Read the selected personal profile if present. It is optional. Use its conversation preferences for your own replies. Use its authoring preferences only when drafting on the user's behalf. Voice preferences can shape wording, tone, and how you group questions. They do not change authorship, facts, explicit instructions, or required approvals.

Keep the user's language and examples as provided. The language of these instructions does not set the language of the profile, its source material, or the conversation. If calibrating a profile, use only sources the user has selected and ask before saving changes. Leave existing profiles and examples untouched otherwise.
